# Guía de contribución

Gracias por contribuir a la documentación defensiva.

## Requisitos

- Utiliza español claro y términos técnicos consistentes.
- Añade una fuente verificable a las afirmaciones técnicas específicas.
- Distingue hechos, hipótesis y recomendaciones.
- No incluyas muestras ejecutables, datos privados ni instrucciones para desplegar malware.
- Revisa enlaces y fecha de consulta.

## Proceso

1. Crea una rama para tu cambio.
2. Explica el propósito y el alcance de la modificación.
3. Comprueba los enlaces y la ortografía.
4. Abre un pull request con resumen, fuentes y limitaciones.
