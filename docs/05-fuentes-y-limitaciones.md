# 5. Fuentes, referencias y limitaciones

## 5.1 Fuentes técnicas recomendadas

1. **Android Developers — Permisos en Android**  
   https://developer.android.com/guide/topics/permissions/overview  
   Referencia oficial para comprender permisos, datos restringidos y buenas prácticas de minimización.

2. **Android Developers — Lineamientos de seguridad**  
   https://developer.android.com/privacy-and-security/security-tips  
   Recomendaciones de seguridad de aplicaciones y del ecosistema Android.

3. **Android Developers — Prácticas recomendadas de permisos**  
   https://developer.android.com/training/permissions/usage-notes  
   Orientación sobre la solicitud contextual de permisos y el tratamiento de datos sensibles.

4. **Android Debug Bridge (ADB)**  
   https://developer.android.com/tools/adb  
   Documentación oficial de la herramienta de diagnóstico Android.

5. **MITRE ATT&CK for Mobile**  
   https://attack.mitre.org/matrices/mobile/  
   Marco de referencia para organizar técnicas observadas en amenazas móviles. No es una fuente específica de atribución a WannaLocker.

6. **Informe comunitario sobre análisis de malware Android (referencia para iniciar investigación)**  
   https://github.com/latosa28/Android-Malware-Analysis  
   Recurso comunitario que menciona WannaLocker. Contrasta cualquier afirmación con informes técnicos primarios antes de citarla como hecho confirmado.

## 5.2 Cómo citar nuevas fuentes

Para cada informe técnico añadido, registra:

- Autor u organización.
- Título del informe.
- Fecha de publicación.
- URL permanente.
- Fecha de consulta.
- Afirmación concreta que respalda.
- Limitaciones o posibles conflictos de interés.

Prioriza análisis técnicos de proveedores reconocidos, organismos de seguridad o investigación académica. Evita usar publicaciones sin autor o que repitan información sin citar una fuente primaria.

## 5.3 Limitaciones de este repositorio

- No contiene muestras reales de WannaLocker.
- No afirma que todos los comportamientos descritos en ransomware móvil sean propios de cada variante de WannaLocker.
- Los indicadores y permisos requieren interpretación contextual.
- No ofrece una herramienta de detección certificada ni garantiza identificar variantes nuevas, ofuscadas o empaquetadas.
- La recuperación de archivos depende de la variante, el estado del dispositivo y la existencia de copias de seguridad o métodos de recuperación verificados.
- Las fuentes externas pueden actualizarse o desaparecer; verifica su vigencia al entregar el proyecto.

## 5.4 Criterios para conclusiones

Una conclusión sólida debe poder rastrearse hasta una fuente o evidencia concreta. Distingue entre **observado**, **reportado por una fuente**, **inferido** y **no confirmado**. No atribuyas una muestra a WannaLocker solo por su nombre, una nota de rescate o una coincidencia de cadena.
