# Política de seguridad

Este repositorio es documental y educativo. No envíes muestras de malware, credenciales, datos personales ni registros privados mediante incidencias públicas.

Para informar de un error de documentación, abre una incidencia con una descripción reproducible y sin datos sensibles. Si un hallazgo involucra una vulnerabilidad de un producto externo, utiliza el canal de divulgación responsable del proveedor correspondiente.

Utiliza la información únicamente para investigación defensiva autorizada. Este repositorio no proporciona asesoramiento de respuesta a incidentes para un caso específico ni garantiza la seguridad de una aplicación o dispositivo.
